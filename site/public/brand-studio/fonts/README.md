# Brand Studio fonts

The 25 display faces and the two body faces (Figtree, DM Sans) used by `/brand/` are open-source
fonts under the SIL Open Font License 1.1 (https://openfontlicense.org), taken from Fontsource
(https://fontsource.org) as Latin-subset `.woff2` files. They are loaded on demand with the FontFace
API (`src/scripts/brand-studio/fonts.ts`), never from a stylesheet.

Bagel Fat One, Shrikhand, Titan One, Fredoka, Unbounded, Rye, Bodoni Moda, Abril Fatface, Poiret One,
Italiana, Big Shoulders Display, Limelight, Michroma, Syncopate, Syne, Space Grotesk, Righteous,
Gloock, Cherry Bomb One, Gochi Hand, Permanent Marker, Bricolage Grotesque, Bungee, Josefin Sans,
Comfortaa, Figtree and DM Sans.
