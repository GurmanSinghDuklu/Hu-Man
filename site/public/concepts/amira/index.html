    How I work at the bench

    Four habits I bring to every experiment, whatever the technique.

    • 1

      Label everything

      Tubes, plates and notebook pages all carry a date, a name and a sample code, so nothing is ever a mystery later.

    • 2

      Run the controls

      A positive, a negative and a blank on every plate. If the controls look wrong, the results do not count.

    • 3

      Write it as I go

      Methods, deviations and small surprises go in the notebook at the time, not from memory at the end of the day.

    • 4

      Explain it plainly

      If I can tell a ten year old what the experiment is for, I understand it well enough to run it properly.
